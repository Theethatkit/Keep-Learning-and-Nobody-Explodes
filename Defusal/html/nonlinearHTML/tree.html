01 — UNDERSTAND

What is a Tree?

Concept

A tree is a non-linear data structure that organizes information into parent–child relationships. Unlike an array or linked list, its elements are not arranged in one continuous sequence.

The first node is called the root. Each node may connect to child nodes, producing branches and smaller subtrees.

🌳

Think of a family tree

One person can have several children, and each child can become the parent of another group. This creates multiple levels instead of one straight line.

R

Root

The topmost node. It has no parent.

P

Parent

A node directly connected above another node.

C

Child

A node directly connected below a parent.

L

Leaf

A node that does not have any children.

D

Depth

The number of edges from the root to a node.

H

Height

The longest path from a node to a leaf.

TRAVERSAL GUIDE

How is Each Traversal Different?

N-L-R

Preorder

Visit Node, then Left subtree, then Right subtree.

Node → Left → Right
L-N-R

Inorder

Visit Left subtree, then Node, then Right subtree.

Left → Node → Right
L-R-N

Postorder

Visit Left subtree, Right subtree, and then Node.

Left → Right → Node
BFS

Level Order

Visit nodes one level at a time using a queue.

Top → Bottom
Useful observation: Inorder traversal of a Binary Search Tree returns its values in ascending order.
