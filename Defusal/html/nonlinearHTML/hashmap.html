01 — UNDERSTAND

What is a Hash Map?

Concept

A Hash Map stores information as key–value pairs. Instead of searching through every element, it uses a hash function to calculate where a key should be stored.

COLLISION HANDLING

What Happens When Keys Collide?

A collision occurs when two different keys produce the same bucket index. A Hash Map must have a strategy for storing both entries.

01

Separate Chaining

Every bucket stores a linked list of entries. Colliding entries are added to the same chain.

[1] AB → BA
Used in this visualization
02

Open Addressing

If a bucket is occupied, the algorithm searches for another available bucket.

EFFICIENCY

Time Complexity

Operation Average Worst Explanation
Put O(1) O(n) A long collision chain may be searched.
Get O(1) O(n) Entries in the same bucket are compared.
Remove O(1) O(n) The key must be found before removal.
Contains Key O(1) O(n) Uses the same process as Get.
Important: O(1) is the average case. Performance depends on a good hash function, a suitable capacity, and a controlled load factor.
