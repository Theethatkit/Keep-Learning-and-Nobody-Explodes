HASH-BASED DATA STRUCTURE

HashMap

Learn how a HashMap stores key-value pairs and uses a hash function to locate values efficiently.

What is a HashMap?

A HashMap is a data structure that connects keys to values. It uses a hash function to convert each key into an index inside an array of buckets.

It is similar to a dictionary. You use a word as the key to quickly find its corresponding meaning, which is the value.

Why Do We Need HashMaps?

Searching for a value inside an unsorted array normally requires checking elements one by one, which takes O(n).

A HashMap uses a key to calculate the location of a value. This allows insertion, lookup and removal to take O(1) average time.

Array Search O(n)

Check values one by one.

HashMap Lookup O(1) average

Calculate the bucket from the key.

Key Components of Hashing

Key

A unique identifier used to locate its corresponding value.

Value

The data stored and associated with a key.

Hash Function

Converts a key into a bucket index.

Bucket

A position where one or more key-value pairs are stored.

Key → Hash Code → Index = Hash Code % Bucket Count

Basic Operations and Time Complexity

Operation Description Average Worst Case
Put Add or update a key-value pair. O(1) O(n)
Get Retrieve a value using its key. O(1) O(n)
Remove Delete a key-value pair. O(1) O(n)
containsKey Check whether a key exists. O(1) O(n)

Operations may become O(n) in the worst case when many keys collide in the same bucket.

Collision in Hashing

A collision occurs when two different keys produce the same bucket index. A HashMap must handle collisions without losing either value.

Chaining

Each bucket stores a list of key-value pairs. Keys that produce the same index are placed inside the same bucket.

When a bucket is occupied, the HashMap searches for another available bucket using a probing method.

Applications of HashMaps

Database Indexing

Keys help databases retrieve records quickly.

Caching

Previously calculated results can be stored and retrieved using their input as a key.

DNS Resolution

Domain names can be connected to their corresponding IP addresses.

Symbol Tables

Compilers use HashMaps to store variables, functions and other identifiers.

Advantages

  • Fast O(1) average insertion and lookup.
  • Keys can represent meaningful identifiers.
  • Suitable for large collections of key-value data.
  • Existing values can be updated using their keys.

Disadvantages

  • Additional space is required for unused buckets.
  • Collisions require special handling.
  • Many collisions can reduce performance to O(n).
  • Entries do not normally follow a meaningful order.
