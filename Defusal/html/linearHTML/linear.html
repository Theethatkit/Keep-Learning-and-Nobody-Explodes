LINEAR DATA STRUCTURES

Learn Linear Data Structures

A linear data structure organizes elements sequentially. Each element normally has one element before it and one element after it, except the first and last elements.

Linear data structures are easy to traverse because their elements can be visited one by one from the beginning to the end.
