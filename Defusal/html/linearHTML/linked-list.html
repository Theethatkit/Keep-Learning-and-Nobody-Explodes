Linked List

Follow connections between nodes and discover why linked lists change links instead of shifting values.

01 / UNDERSTAND

A sequence formed by connected nodes.

A linked list stores data inside nodes. Each node contains a value and one or more pointers that connect it to other nodes.

Unlike an array, linked-list nodes do not need to occupy neighboring memory locations. The sequence is determined by its pointers.

By the end, you should be able to:

  • Identify Head, Tail, Data, Next, Previous and NULL.
  • Follow pointers to reach a given position.
  • Insert and delete nodes by changing connections.
  • Compare singly, circular and doubly linked lists.
  • Explain the time complexity of each operation.

Node

Stores a value and pointer information.

Head

Points to the first node. An empty list has Head = NULL.

Next

Points to the next node in the sequence.

Tail

The final node. In a normal singly list, Tail.next is NULL.

Position is not direct access

Positions can be numbered 0, 1, 2 and so on, but a linked list cannot calculate a node's address directly from its position. It must follow pointers from Head.

02 / TYPES

Three ways to connect nodes.

Singly Linked List

Each node has one Next pointer. Movement is possible from Head toward Tail only.

10 → 20 → 30 → NULL

Circular Singly Linked List

Tail.next points back to Head. There is no NULL pointer at the end of the cycle.

10 → 20 → 30 ↺ Head

Doubly Linked List

Each node has Previous and Next pointers, allowing traversal in both directions.

NULL ← 10 ⇄ 20 ⇄ 30 → NULL
Which type is used in the interactive lab?

You can select all three types. The stored values remain the same when the type changes, but the displayed connections and traversal rules change.

03 / OPERATIONS

Finding a node and changing links are different costs.

Operation Singly Doubly Condition
Insert Front O(1) O(1) Change Head and nearby pointers.
Insert Back O(1)* O(1)* *When a Tail pointer is maintained.
Insert at Position O(n) O(n) Traversal may be needed to find the position.
Delete Front O(1) O(1) Move Head to the next node.
Delete Back O(n) O(1)* Singly must find the predecessor. *Doubly needs a Tail pointer.
Search / Traversal O(n) O(n) Nodes may need to be checked one by one.

Important distinction

Changing a constant number of pointers is O(1). However, finding the correct node or predecessor from Head may require O(n) traversal first.

    07 / APPLY

    Choose the correct structure.

    Stack

    Use Head as the top for O(1) push and pop.

    Queue

    Maintain Head and Tail for O(1) enqueue and dequeue.

    Browser navigation

    Previous and Next links support backward and forward movement.

    Hash chaining

    Nodes in the same hash bucket can be linked.

    Round-robin tasks

    A circular list can repeatedly cycle through active tasks.

    LRU cache

    A doubly linked list supports moving and removing known nodes efficiently.

    Investigation

    1. Reset the visualization.
    2. Insert 5 at the front.
    3. Reset and insert 25 at position 2.
    4. Compare how many pointers were followed.
    5. Explain why existing node values did not shift.
    Check your explanation

    Front insertion changes Head immediately. Insertion at position 2 first finds the predecessor. Both operations reconnect nodes rather than moving the existing values.

    Advantages

    • Can grow or shrink during runtime.
    • Front insertion and deletion take O(1).
    • Nodes do not need contiguous memory.
    • Known nodes can be reconnected efficiently.

    Limitations

    • No O(1) random access by position.
    • Pointers require additional memory.
    • Separate allocations may reduce cache locality.
    • Incorrect pointer handling can lose nodes.
