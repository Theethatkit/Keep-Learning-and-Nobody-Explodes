LINEAR DATA STRUCTURE

Linked List

Learn how linked lists store data using nodes and pointers, and compare singly and doubly linked lists.

Introduction

A linked list is a linear data structure where elements are stored as nodes connected using pointers. Unlike an array, linked list nodes do not need to be stored in contiguous memory locations.

A linked list can grow or shrink during runtime, making it suitable for data whose size changes frequently.

TYPE ONE

Singly Linked List

In a singly linked list, each node stores a value and a pointer to the next node. Movement is possible in one direction only.

Node

An element containing a value and a next pointer.

Head

A reference pointing to the first node.

Next Pointer

Stores a reference to the following node.

Tail

The final node. Its next pointer contains null.

Head
10 next
→
20 next
→
30 next
→ null

Traversal starts at the head and follows each next pointer.

Circular Singly Linked List

In a circular singly linked list, the tail node points back to the head instead of pointing to null. Storing the tail gives direct access to both the last node and the first node.

↻

Tail.next points to Head, forming a continuous loop.

TYPE TWO

Doubly Linked List

A doubly linked list is similar to a singly linked list, but every node also stores a previous pointer. This enables traversal in both directions.

Value

The data stored inside the node.

Next Pointer

Points to the next node.

Previous Pointer

Points to the previous node.

Two-way Traversal

The list can be traversed forward and backward.

null ←
prev 10 next
⇄
prev 20 next
⇄
prev 30 next
→ null

Basic Operations and Time Complexity

Operation Description Complexity
Insert Front Add a new node before the head. O(1)
Insert Back Add a node after the tail when a tail reference is available. O(1)
Delete Front Move the head to the next node. O(1)
Delete Back Remove the tail using the previous pointer in a doubly linked list. O(1)
Access / Traversal Follow pointers until the target is reached. O(n)
Search Check nodes one by one. O(n)

Insertion or deletion around a known node in a doubly linked list can be performed in O(1).

Applications

Dynamic Memory

Stores data whose size can grow or shrink during runtime.

Stacks

A stack can use the head as its top for O(1) push and pop.

Queues

A queue can use head and tail pointers for O(1) enqueue and dequeue.

Music Player

A doubly linked list supports moving to the next and previous songs.

Browser History

Previous and next pointers support backward and forward navigation.

LRU Cache

Recently used items can be moved or removed efficiently.

Advantages

  • The list can grow or shrink during runtime.
  • Front insertion and deletion can be performed in O(1).
  • Nodes do not require contiguous memory.
  • Doubly linked lists support two-way traversal.

Disadvantages

  • Elements cannot be accessed directly using an index.
  • Access and search normally require O(n).
  • Every node requires additional memory for pointers.
  • Pointer updates make the implementation more complex.
