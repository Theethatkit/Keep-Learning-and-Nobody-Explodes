Linear Data Structure

Array

Learn how arrays store data, how array indexes work, and how basic array operations are performed.

Introduction

An array is a collection of elements of the same data type stored in contiguous memory locations. It is one of the simplest and most commonly used data structures in programming.

Array Structure

  • Array Element: An individual value stored in an array.
  • Array Index: A number representing the position of an element. In most programming languages, indexes start from 0.
  • Array Length: The total number of elements stored in an array.

Basic Operations and Time Complexity

Access

Retrieves an element using its index.

O(1)

Update

Changes the value stored at a specified index.

O(1)

Insert

Adds a new element and may require shifting other elements.

O(n)

Delete

Removes an element and may require shifting the remaining elements.

O(n)

Search

Finds an element by checking the array values.

O(n)

Traversal

Visits every element in the array one by one.

O(n)

Applications

Arrays provide fast random access and good cache performance. They are commonly used in many programs and algorithms.

Store Information

Store student scores, names, prices, or temperatures.

Matrices

Represent tables, grids, and mathematical matrices.

Algorithms

Support searching, sorting, and data-processing algorithms.

Other Structures

Arrays can be used to implement stacks and queues.

Advantages

  • Efficient and Fast Access: Elements can be accessed directly using an index.
  • Memory Efficiency: Elements are stored next to one another in memory.
  • Versatility: Arrays can represent lists, tables, and matrices.
  • Hardware Compatibility: Arrays work efficiently with low-level memory operations.

Disadvantages

  • Fixed Size: A normal array cannot easily change its size.
  • Memory Allocation Issues: An oversized array may waste memory.
  • Insertion and Deletion: Other elements may need to be shifted.
  • Same Data Type: Elements normally need to have the same data type.
