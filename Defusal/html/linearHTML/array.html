01 / UNDERSTAND

Find a value by its position.

Imagine storing seven daily temperatures. Rather than creating seven separate variables, an array groups them under one name. An index identifies each position.

In C, an array stores elements of the same type in contiguous memory locations. Indexes start at 0. This lesson uses that conventional array model.

By the end, you should be able to:

  • Distinguish an index from an element's value.
  • Trace access, update, insertion and deletion.
  • Explain linear search and traversal.
  • Read and modify C code for each operation.
  • Explain why some operations need O(n) time.

Element

An individual stored value, such as 30.

Index

A position used to access an element, such as index 2.

Size vs capacity

Size counts active elements. Capacity counts available storage slots.

Why is access O(1)?

For a conventional array, an element's address can be calculated from the starting address, its index and the element size: 

address(a[i]) = base_address + i * element_size

We do not need to inspect earlier elements to reach a valid index.

02 / OPERATIONS

What changes, and what does it cost?

Let n be the number of active elements. Insertion and deletion below preserve element order.

Access

Read an existing position. Nothing moves.

O(1)

Update

Replace one value. Size stays the same.

O(1)

Insert

Shift elements right to make room. Requires spare capacity.

O(n) worst case

Delete

Shift later elements left to close the gap.

O(n) worst case

Linear search

Compare values until a match is found or all elements have been checked.

O(n) worst case

Traversal

Visit every active element once.

O(n)

Important conditions

  • Inserting at the end is O(1) when spare capacity exists.
  • Deleting the last active element needs no shifts.
  • A fixed array cannot grow its allocated capacity. A dynamic array may allocate larger storage and copy elements.
  • Linear search works on unsorted data. Binary search requires sorted data and takes O(log n) comparisons.
Common mistake: update is not insertion

Starting with [10, 20, 30], updating index 1 to 99 gives [10, 99, 30].

Inserting 99 at index 1 gives [10, 99, 20, 30]. Existing values are preserved and size increases.

    06 / APPLY

    Choose the right structure.

    Daily measurements

    An array is useful when readings have known positions and you often access them by index.

    Grids and matrices

    Multidimensional arrays can represent a game board or a matrix.

    Stacks and queues

    Arrays can store both. A circular queue avoids shifting items on every dequeue.

    Investigation: where should you insert?

    1. Reset the lab. Insert 99 at index 0.
    2. Finish the trace and count the shifts.
    3. Reset again. Insert 99 at index 4.
    4. Explain why the same operation has different costs.
    Check your explanation

    Inserting at index 0 shifts all four values. Inserting at index 4 appends the value and shifts none. Both write the new value once.

    Worst-case insertion takes O(n), while appending with spare capacity takes O(1).

    Advantages

    • O(1) access to a valid index.
    • Contiguous storage often helps cache locality.
    • No per-element next pointer is needed.
    • Useful for tables, grids and indexed records.

    Limitations

    • A fixed array has a fixed allocated capacity.
    • Ordered insertion and deletion may shift values.
    • Unused capacity still occupies storage.
    • In C, accessing outside allocated array bounds can cause undefined behavior.
