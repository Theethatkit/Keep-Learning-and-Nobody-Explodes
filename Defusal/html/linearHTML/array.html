LINEAR DATA STRUCTURE

Array

Learn how arrays store elements, how indexes work and how basic array operations are performed.

Introduction

An array is a collection of elements of the same data type stored in contiguous memory locations. It is one of the simplest and most commonly used data structures in programming.

Array Structure

  • Array Element: An individual value stored in the array.
  • Array Index: A number representing the position of an element. Indexes normally begin at 0.
  • Contiguous Memory: Array elements are stored next to one another in memory.

Basic Operations and Time Complexity

Access

Retrieve an element directly using its index.

O(1)

Update

Change the value stored at a specified index.

O(1)

Insert

Add a new element and shift the following elements when necessary.

O(n)

Delete

Remove an element and shift the remaining elements.

O(n)

Search

Find an element by checking values one by one.

O(n)

Traversal

Visit every element in the array from beginning to end.

O(n)

Applications

Matrices

Arrays can represent tables, grids and mathematical matrices.

Stacks

Arrays can implement stacks by using the final index as the top.

Queues

Arrays can implement queues, although a simple implementation may require shifting elements.

Advantages

  • Elements can be accessed directly using an index.
  • Elements are stored next to one another in memory.
  • Arrays can represent lists, tables and matrices.
  • Arrays work efficiently with low-level memory operations.

Disadvantages

  • A fixed-size array cannot change its size after initialization.
  • Insertion and deletion may require other elements to be shifted.
  • Elements normally need to have the same data type.
