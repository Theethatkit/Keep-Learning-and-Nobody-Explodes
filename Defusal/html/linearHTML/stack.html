LINEAR DATA STRUCTURE

Stack

Learn how a stack follows the Last In, First Out principle and performs all operations from the top.

Introduction

A stack is a linear data structure where elements are inserted and removed from the same side. It follows the LIFO principle: Last In, First Out.

This means that the most recently added element is the first element to be removed.

LIFO Principle

  • New elements are pushed onto the top.
  • Elements are also removed from the top.
  • The latest element added is removed first.
  • The oldest element remains at the bottom.

Stack Structure

Top

The side where push, pop and peek operations are performed.

Bottom

The oldest element stored inside the stack.

LIFO

The last element inserted is the first one removed.

One Open End

Insertion and deletion occur at the same end.

Basic Operations and Time Complexity

Push

Add a new element to the top of the stack.

O(1)

Pop

Remove the element currently at the top.

O(1)

Peek / Top

Read the top element without removing it.

O(1)

isEmpty

Check whether the stack contains no elements.

O(1)

Implementation

Array

An array can implement a stack by using its final index as the top. Push and pop at the end normally take O(1).

Dynamic Array

Push takes O(1) amortized time. Resizing occasionally takes O(n), but most push operations take O(1).

Linked List

A linked list can use its head as the top, allowing push and pop operations in O(1).

Applications

Browser Back Button

Visited pages are pushed onto a stack. Pressing Back pops the current page and returns to the previous page.

Function Call Stack

The most recently called function finishes before execution returns to the previous function.

Undo and Redo

Recent actions can be stored and removed in reverse order.

Expression Evaluation

Stacks help process brackets, operators and mathematical expressions.

Advantages

  • Push, pop and peek take O(1).
  • It can be implemented easily using an array.
  • It naturally supports undo, browser history and nested function calls.

Disadvantages

  • A static array implementation has a fixed size.
  • Dynamic array resizing occasionally takes O(n).
  • Random access is not supported because only the top element is directly available.
