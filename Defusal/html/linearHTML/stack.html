01 / UNDERSTAND

The last item inserted leaves first.

A stack is a linear data structure where insertion and removal happen at the same end, called the Top.

It follows LIFO: Last In, First Out. Imagine a stack of plates—the final plate placed on top is normally the first plate removed.

By the end, you should be able to:

  • Explain LIFO using an operation sequence.
  • Perform Push, Pop, Peek and isEmpty.
  • Recognize stack overflow and underflow.
  • Compare array and linked-list implementations.
  • Use a stack to reverse a sequence.

Push sequence

  1. Push 10: 10 becomes Top.
  2. Push 20: 20 becomes Top.
  3. Push 30: 30 becomes Top.
  4. Pop: 30 leaves first.

Pop and Peek are not the same

Both operations inspect the Top. Pop removes and returns it, while Peek returns it without changing the stack.

02 / OPERATIONS

Every main operation uses the Top.

Push(value)

Add value to the Top.

O(1)

Pop()

Remove and return the Top value.

O(1)

Peek()

Read the Top without removing it.

O(1)

isEmpty()

Check whether the stack has zero elements.

O(1)

Size

Return the number of active elements.

O(1)

isFull()

Check whether a fixed-capacity stack has no available slot.

O(1)

Two important errors

  • Overflow: Push is attempted when a fixed-capacity stack is full.
  • Underflow: Pop or Peek is attempted when the stack is empty.

Implementation choices

Fixed array

Has a maximum capacity. Push, Pop and Peek take O(1).

Dynamic array

Push is O(1) amortized but resizing can occasionally take O(n).

Linked list

Head can act as Top. Push and Pop are O(1) while memory is available.

Applications

Function calls

The most recent unfinished call returns first.

Undo and redo

Recent actions are processed in reverse order. Redo normally requires a second stack.

Bracket matching

Opening brackets are pushed and matched against closing brackets.

Depth-first search

Pending vertices can be stored in an explicit stack.

Advantages

  • Push, Pop and Peek take O(1).
  • The LIFO rule is simple and predictable.
  • Useful for nested or reverse-order tasks.

Limitations

  • Only the Top is directly accessible.
  • A fixed array has limited capacity.
  • Searching an arbitrary item takes O(n).
