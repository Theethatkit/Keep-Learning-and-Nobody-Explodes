LINEAR DATA STRUCTURE

Queue

Learn how a queue processes elements using the First In, First Out principle.

Introduction

A queue is a linear data structure that processes elements in the order they are received. It follows FIFO: First In, First Out.

The first element added to the queue is the first element to be removed.

FIFO Principle

A queue works like a line of people waiting for service. The first person to enter the line is the first person to leave the line.

Queue Structure

Front

The position of the next element to be removed.

Rear

The position where a new element is inserted.

FIFO

The first element inserted is removed first.

Flow

Insert at Rear → Queue → Remove from Front.

Basic Operations and Time Complexity

Enqueue

Add a new element to the rear of the queue.

O(1)

Dequeue

Remove the element at the front of the queue.

O(1)

Peek / Front

Access the front element without removing it.

O(1)

isEmpty

Check whether the queue contains no elements.

O(1)

Implementation

Implementation Enqueue Dequeue Notes
Array: rear at the end O(1) O(n) Dequeue requires the remaining elements to be shifted.
Array: rear at the beginning O(n) O(1) Enqueue requires the existing elements to be shifted.
Singly Linked List O(1) O(1) Use the head as the front and the tail as the rear.

With a simple array, one operation normally requires O(n) shifting. A linked list with head and tail pointers supports both operations in O(1).

Applications

Server Requests

Requests can be processed one by one in their order of arrival.

Music Player

Songs can be played according to their order in the queue.

Waiting Lines

The first person to enter the line is served first.

Advantages

  • Maintains the order in which elements arrive.
  • Enqueue and dequeue can take O(1) with a linked list implementation.
  • Suitable for scheduling and sequential processing.

Disadvantages

  • A simple array implementation may require O(n) shifting.
  • A fixed-size array queue can overflow.
  • Elements in the middle cannot be accessed directly.
