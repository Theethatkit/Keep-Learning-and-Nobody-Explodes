01 / UNDERSTAND

The earliest arrival leaves first.

A queue follows FIFO: First In, First Out. New elements enter at the Rear, while the oldest element leaves from the Front.

Imagine people waiting for service. A new person joins the end of the line, while the person waiting longest is served first.

By the end, you should be able to:

  • Explain FIFO using an operation sequence.
  • Perform Enqueue, Dequeue and Peek.
  • Recognize queue overflow and underflow.
  • Trace Front and Rear in a circular queue.
  • Compare simple-array, circular-array and linked queues.

Front

The position of the next value to be removed.

Rear

In this lesson, Rear is the next position where a value will be inserted.

Size

The number of active values in the queue.

Capacity

The number of slots allocated to a fixed queue.

Why do we also store Size?

In a circular queue, Front and Rear can be equal when the queue is empty or full. Size distinguishes those two states.

Advantages

  • Preserves arrival order.
  • Circular Enqueue and Dequeue take O(1).
  • Suitable for scheduling and buffering.

Limitations

  • Only Front and Rear are directly used.
  • A fixed queue can overflow.
  • Incorrect index handling can break wrap-around.
